# 💡 Запустите приложение и смотрите вывод в консоль.

Можно оставить только интересующие вас срезы:
- spring - жизненный цикл Spring'а.
- event - события.
- bean - жизненный цикл бина.
- injection - инъекции
- detective - детективная история 🔍

  
Используйте так: -Dslice=spring

Или через запятую: -Dslice=spring,injection
